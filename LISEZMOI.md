# Jeu Before Race

- `index.html` : le jeu (le même moteur pour Son Mystère, Commissaires FIA et L'Intrus).
- `donnees.js` : le contenu du jeu (vidéos, réponses, début/fin des extraits). C'est le seul fichier à modifier.

## Mettre en ligne
GitHub Pages ne marche qu'avec un dépôt **public** sur un compte gratuit.
Le jour venu : **Settings → General → Change visibility → Public**, puis **Settings → Pages** → branche `main`, dossier `/ (root)` → **Save**.
Le site sera sur `https://liteunderscore.github.io/NOM-DU-DEPOT/` après 1 à 2 minutes.

Dans OBS : Source navigateur, 1920 × 1080, « Contrôler l'audio via OBS » coché.

## Touches
| Touche | Action |
|---|---|
| Espace | Lecture / pause |
| Entrée | Révéler la réponse |
| T / X | Trouvé / Raté |
| → / ← | Suivant (après la réponse) / précédent |
| R | Rejouer l'extrait |
| M | Couper le son |
| S | Réglages (début / fin de l'extrait) |
| C | Masquer les boutons |
